# Podcast app

A personal iOS podcast app: smart Up Next queue, on-device transcripts,
ad skipping, chapters, Discover.

- `CLAUDE.md`: project brief and decisions (start here).
- `notes/DESIGN.md`: look, colours, type and screen specs.
- `notes/SETUP.md`: cloud build and TestFlight setup (no Mac needed).
- `design/`: screen mockups, one file per screen.
